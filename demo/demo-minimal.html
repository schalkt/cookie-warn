cookie-warn/Minimal theme

data-theme="minimal"
← All demos

The minimal theme applies almost no styling — it inherits the page font, uses a frosted glass background, and renders small neutral buttons. Ideal for slotting into an existing site without overriding its design language.

  • Nearly zero own styling — inherits page font and color
  • Frosted glass background (backdrop-filter: blur)
  • Small neutral buttons, easy to override with data-style
  • Simulated serif body font to show theme adaptability
